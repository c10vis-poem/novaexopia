# Node.js LTS

**Slug:** `node-js` · **Kind:** runtime (executes code)

## What it is

node + npm/pnpm

**Target hardware:** any

## Notes

Runs MCP servers, OpenWiki, web tooling.

## Do not confuse with

An *engine* — an engine wraps this plus a model plus a scheduler. This is the
layer that actually executes.
